# KkModal 弹窗

浮层容器，用于承载需要打断当前流程的内容，支持头部 / 底部插槽与拖动。

## 何时使用

- 需要用户确认或补充信息，且不适合跳转新页面；
- 需要展示较长内容但不想挤压主页面布局；
- 需要在页面上对比、拖开参考信息（开启 `draggable` 后可拖到任意位置）。

## 设计要点

- **遮罩与主体分层**：`.kk-modal__overlay` 负责遮罩、居中与留白，`.kk-modal` 只负责自身外观与拖动位移；
- **顶部留白与最大高度联动**：`max-height` 取「组件 token」与 `100vh - 顶部留白 - 底部留白` 的较小者，长内容由主体区域内部滚动，不会把弹窗顶出屏幕；
- **拖动只走合成层**：位移写在 `transform: translate3d()` 上，全程不触发重排；`will-change` 只在拖动期间叠加，不常驻占用显存；
- **默认不销毁 DOM**：首次打开后仅切换可见性，二次打开不重新挂载；需要彻底销毁时用 `destroyOnClose`。

## 性能约定

| 场景         | 处理方式                                                             |
| ------------ | -------------------------------------------------------------------- |
| 拖动过程     | 直接写元素内联 `transform`，不进入响应式渲染                         |
| 指针事件     | `setPointerCapture` 挂在弹窗自身，无需 document 级监听，移出窗口不断 |
| body 滚动锁  | 引用计数，多弹窗嵌套各自释放不会互相解锁                             |
| 打开 / 关闭  | 首帧先挂载再显示，保证入场动画播放；之后只切 `v-show`                |
| 减少动效偏好 | 过渡在 `prefers-reduced-motion: reduce` 下整体关闭                   |

## 无障碍

- 根节点带 `role="dialog"`、`aria-modal="true"`；
- 有标题时自动用 `aria-labelledby` 关联，无标题建议传 `aria-label`；
- 打开后焦点移入弹窗，`Tab` 在弹窗内循环，关闭后焦点回到打开前的元素；
- `Esc` 关闭可通过 `closeOnEsc` 关闭。
