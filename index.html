KK UI 以「柔光几何」为设计语言，提供轻量、圆润、有呼吸感的组件体验。 完整 TypeScript 支持，主题一键切换。

$ pnpm add kk-ui
Features

为什么选择 KK UI

在严谨、实用与轻盈之间，KK 用三层 Token 与柔光几何找到了自己的位置。

多主题系统
4 套内置主题，三层 CSS 变量架构，运行时动态切换，并支持注册自定义主题。
完整 TypeScript
全部使用 script setup 与 defineProps 泛型，Props、Events、Slots 类型完整导出。
按需引入
每个组件独立目录、独立样式入口，构建产物同时提供 ES 与 CJS 格式。
柔光几何设计
双层阴影、柔和焦点环、圆润圆角，让界面更有层次与呼吸感。
无障碍支持
语义化标签、ARIA 属性、键盘可达与可见焦点环，交互状态可辨识。
配套文档与测试
每个组件都包含组件、类型、样式、测试、README，交付即完整。
